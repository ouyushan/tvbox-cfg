# 2026-09-30

## 建立 tvbox-cfg 自用配置仓库

- 目标：检索 GitHub 上 star 靠前的 TVBox 配置源仓库，整理成本地自用仓库，同步到 https://github.com/ouyushan/tvbox-cfg
- 检索方式：GitHub Search API（未认证，注意 10 次/分钟的限流）+ 抓 raw.githubusercontent.com 上的 README 提取配置地址
- 收录结果：19 个点播源、4 个直播源、24 个上游仓库索引、GitHub 加速镜像清单，全部实探测活（50/51 ok）
- 仓库结构：
  - `sources/` 为单一事实来源（vod.json / live.json / mirrors.json / upstream.json）
  - `config/` 为生成产物（multi.json 多仓聚合 jsdelivr 版、multi-raw.json、live.json）
  - `scripts/build.py` 生成配置，`scripts/check.py` 批量探活并回写 status
  - `.github/workflows/check.yml` 每 6 小时自动探活
- TVBox 多仓配置格式确认为 `{"urls":[{"url":...,"name":...}]}`；单仓为 `{"spider":...,"lives":[...],"sites":[...]}`
